🚀 Personal Portfolio Website 

📌 Overview

This is a full-stack personal portfolio website built to showcase my projects, skills, and technical profile.

The application includes:

🌐 Public Portfolio Website

🔐 Admin Login System

    ├── Admin Dashboard to Manage Projects & Skills

💾 Backend API using Spring Boot

🗄 MySQL Database Integration

This project demonstrates my understanding of frontend development, REST APIs, database connectivity, and backend architecture.

🛠 Tech Stack

🔹 Frontend

     ├──HTML5
     ├──CSS3
     ├──JavaScript



🔹 Backend

     ├──Java
     ├──Spring Boot
     ├──Spring Web
     ├──JDBC / JPA
     ├──REST APIs


🔹 Database

    ├──MySQL

🔹 Tools

    ├──IntelliJ IDEA
    ├──Git & GitHub
    ├──MySQL Workbench
    ├──VSCode

✨ Features

👤 Portfolio Section

    ├──Hero section with introduction
    ├──About Me section
    ├──Skills display
    ├──Projects showcase
    ├──Contact section


🔐 Admin Features

    ├──Secure Admin Login
    ├──Add new projects
    ├──Delete projects
    ├──Manage portfolio content dynamically
    ├──Data stored in MySQL database
